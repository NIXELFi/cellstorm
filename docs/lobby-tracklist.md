# Lobby / Scene Music — Tracklist

**Source mix:** `assets/music/lobby-mix.mp3` ("game lobby music") — a ~53-minute compilation of 20 tracks.

The long-form tournament uses this for the **non-battle scenes**. Each scene plays ONE track, seeked to
its start timestamp: the **intro** uses the **first** track, the **podium** uses the **last** track, and
the in-between scenes use **random middle tracks** (never first/last, no repeats — deterministic per
tournament seed). Battle clips use `assets/music/battle-epic-fight.mp3` instead.

Hardcoded in `apps/tournament/src/tracklist.ts` (`LOBBY_TRACKLIST`). Also recorded in CLAUDE.md and
Claude's memory. **Keep all copies in sync — do not lose this list (artist attribution).**
